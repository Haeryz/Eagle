One-slide version of the E1 story. Top row: the image goes through MoonViT and the MLP projector; the prompt is tokenized as text and skips the vision encoder; both are merged and fed to Qwen2.5-3B, which is unchanged. Each forward also takes the 6-slot drafting window, an anchor plus 5 mask tokens, and returns 6 x 152,681 logits. Everything after that is the decoding loop, outside Qwen: (1) sampling turns logits into probabilities; (2) E1, the only change, picks the best of 3 legal templates; label and end blocks with P(box) below 0.6 bypass it to the original decoder; (3) the unchanged uncertainty rule flags coordinates with top-1 below 0.9 and top-4 spread over 60; (4) the router commits the block, or falls back: it commits the box start and the coordinates before the flagged one, then decodes 1 token per forward until the box end and returns to parallel mode. Committed tokens are appended and the next window starts. Bottom left: E1 is DINGO's DP on a 3-template tree grammar, so it scores 3 paths and keeps the best. Bottom middle: on forward 2 of the real trace E1 picks BOX (-4.88), but x1 is flagged (top-1 0.183, candidates spanning 0 to 368), so NTP redoes x1 to y2. Bottom right: alone, E1 is within noise on six benchmarks; format fallbacks were under 1% before and after. Fallback is a confidence problem, so Week 2 trains the model to be less uncertain; on top of that training, E1 cuts LVIS format fallbacks from 1.34% to 0.76% (E3).
