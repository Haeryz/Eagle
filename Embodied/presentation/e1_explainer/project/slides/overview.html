One-slide version of the E1 story. Top: the released LocateAnything-3B pipeline. MoonViT and the projector feed Qwen2.5-3B, which is unchanged. Each forward drafts a whole 6-token box from an anchor plus 5 mask slots, and the LM head returns 6 x 152,681 probabilities. Everything after that is the decoding loop, outside Qwen: sampling, the block decoder, the uncertain-coordinate rule, and routing. A rejected box falls back to NTP, one token per forward. E1 replaces only the block decoder, shown in teal. It applies DINGO's dynamic program to a 3-template box grammar: box, point, empty. Because the grammar is a tree, the DP reduces to scoring 3 paths and keeping the best. It only runs when P(box) at slot 0 is at least 0.6. No training, same weights, off by default. Bottom middle: on forward 2 of the real trace, E1 picks BOX (-4.88 vs -85.3 and -138.2). The unchanged amber rule still flags x1 (top-1 0.183, candidates spanning 0 to 368), so NTP redoes the coordinates. Bottom right: E1 alone is within noise on six benchmarks. Fallback is a confidence problem, not a syntax problem, so Week 2 trains the model to be less uncertain. E1 pays off on top of that: it cuts LVIS format fallbacks from 1.34% to 0.76% (E3).
