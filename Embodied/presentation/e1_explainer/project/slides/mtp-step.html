Zoom into the dashed Qwen boundary for one MTP step. Input: (1) the KV cache of everything already committed, (2) the tokens committed last step, which are processed now and enter the cache, and (3) the 6-slot drafting window: an anchor that copies the last committed token and reuses its position p, then five mask tokens at p+1 to p+5. The mask: the prefix is causal; the window sees the whole prefix and itself bidirectionally, except the original last token, which the anchor replaces. Only the 6 window logits are kept: 6 x 152,681, softmax per slot. Slot 0 should be the box start, slots 1-4 the coordinates, slot 5 the box end. After the step the cache is cut back to the committed length, so the window's keys and values are discarded. This is the mechanism E1 later reads from; E1 changes nothing here.
