Frame 3's pipeline twice. Top: E0, the release. Bottom: E1. Everything is identical and faded except box 2. E0's block decoder is a heuristic frame check plus a top-4 coordinate check and can emit a malformed block, which triggers a format fallback. E1's constrained decoder: (1) gate on P(box) at slot 0 of at least 0.6; if not, the block is handed to the release decoder unchanged (labels, end of output); (2) restrict coordinate slots to the 1001 coordinate tokens; (3) score the three legal templates and keep the best; (4) pass the result to the same uncertain-coordinate rule. No training, same weights, off by default. E1 sits outside Qwen, on the path from LM-head probabilities to committed tokens. Caveat for questions: the original model's few remaining format fallbacks come from blocks with P(box) below 0.6, which the gate leaves to the release decoder.
