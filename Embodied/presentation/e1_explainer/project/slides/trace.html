A real E1 run on the example image: 26 forward passes. Grey cells commit labels or the end token (forward 1: the gate sees P(box) = 0 and hands the label block to the original path). Dark cells are MTP box blocks; four of them are rejected (arrow) and continue as coral NTP runs; car 3 at forward 19 is accepted whole. Zoom on forward 2: slot 0 and slot 5 are certain. E1 scores the templates: BOX -4.88, POINT -85.3, EMPTY -138.2, so BOX wins with coordinates 367, 342, 645, 764. Then the release's amber rule sees slot 1: top-1 0.183 and candidates spanning 0 to 368, so x1 is flagged and only the box-start is committed; NTP redoes the four coordinates. E1 chose the right shape, but uncertainty still forces the fallback. Side notes: E0 and E1 differ in a single token here, a 308/306 tie. And the fallback can hurt: truck y1 was drafted as 150 (ground truth 151) but re-decoded as 72.
