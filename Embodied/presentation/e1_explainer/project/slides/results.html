F1 ±0.7, fallback ±0.5 points: format fallbacks were under 1% to begin with.

Fallback is a confidence problem, not a syntax problem → Week 2 (E2) trains the model to be less uncertain.

Each row is a benchmark. The dot plots show E1 minus E0: grey ring is E0 at zero, teal dot is E1. The grey band is the noise floor measured by re-running E0 with numerically different but equivalent kernels: about 0.12 F1 and 0.4 fallback points. Every change sits within or near that band: F1 within plus or minus 0.7, fallback within plus or minus 0.5 points. Format fallbacks barely move because the original model's few format fallbacks come from blocks with P(box) below 0.6, which E1's gate leaves to the release decoder. Takeaways: E1 guarantees valid boxes with no training; alone it has no measurable effect; fallback is a confidence problem, so Week 2 trains the model to be less uncertain. E1 pays off on top of that training: on LVIS it cuts format fallbacks from 1.34% to 0.76% (E3).
